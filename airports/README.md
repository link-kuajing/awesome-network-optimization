## 📋 选购要点

### 1️⃣ 协议类型
- **Trojan** — 目前最主流协议，速度快、伪装性好，推荐首选
- **SS/SSR** — 经典协议，兼容性好，部分老客户端仍在使用
- **V2Ray/VMess** — 高度可定制，适合进阶用户

### 2️⃣ 专线 vs 普通中转
| 类型 | 特点 | 适合人群 |
|------|------|---------|
| **IEPL专线** | 国内端到国外端全程专线，晚高峰不卡顿 | 对稳定性要求高的用户 |
| **BGP中转** | 多运营商接入，智能路由 | 大多数用户，性价比高 |
| **IPLC专线** | 纯内网专线，延迟极低 | 游戏/实时通信需求 |

### 3️⃣ 流媒体解锁
确认是否能解锁您需要的平台：**Netflix、Disney+、HBO、ChatGPT、Claude、TikTok** 等。

### 4️⃣ 设备数限制
- 个人使用：3~5台设备通常足够
- 家庭共享：需要不限设备或10台以上的方案
- 企业团队：选择不限设备+大流量的套餐
