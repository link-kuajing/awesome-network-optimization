## 一张图看懂机场三层架构

机场的本质是"帮你把流量送到墙外"的批发商。它内部一般分三层：

```
你的设备（手机/电脑/路由器）
        │  ① 入口：客户端接入点（国内边缘节点 / 订阅入口）
        ▼
     入口层
        │  ② 中转：链路传输（直连 / 公网中转 / 专线）
        ▼
     中转层
        │  ③ 落地：目标地区出口服务器（决定你的"海外 IP"长什么样）
        ▼
     落地层 ──→ 访问 Netflix / Google / ChatGPT ...
```

- **入口层**：负责"接住"你的加密流量。国内用户访问入口，网络质量取决于入口与你的距离、运营商互通情况；
- **中转层**：负责把流量从入口送到境外。这是线路成本的大头，也是"直连/中转/专线"差异的来源；
- **落地层**：负责以"目标地区的 IP"替你访问目标网站。**决定解锁和风控表现的其实是这一层**。

下面逐层拆解。

---

## 第一层：入口（本地接入）

入口是机场在国内（或离你近的境外地区）设置的接入点，作用是"收流量"。

- 你订阅里每个节点的 IP 和端口，指向的就是入口；
- 入口质量看两点：**离你远不远**（延迟），以及**你的运营商到它通不通**（电信/联通/移动三网互通，也叫"三网优化"）；
- 有些机场在国内有多个入口，按你的运营商自动调度——这就是套餐描述里"BGP 三网优化"的意思：电信走电信入口、联通走联通入口，谁都快。

对普通用户来说，入口层你基本感知不到，但它决定了"节点延迟"这个数字。延迟高不一定是线路差，可能是入口离你远。

---

## 第二层：中转（转发链路）

入口接住流量后，要把流量送出境。这一段怎么送，决定了套餐是"直连""中转"还是"专线"：

| 类型 | 通俗理解 | 特点 |
|:----|:----|:----|
| **直连** | 入口节点就是境外服务器，流量直接从你的设备出国 | 成本最低，但走公网、晚高峰拥堵、被封风险相对高 |
| **中转** | 流量先到国内/香港的转发服务器，再由它走优质线路出境（常见 BGP 中转） | 比直连稳，能绕开部分拥堵段；价格中等 |
| **专线** | 转发段租用运营商级内网专线（IEPL/IPLC），不走公网 | 最稳、抗封锁最强，价格最高 |

关键点：**中转服务器自己不出网**，它只负责"转"，真正替你访问目标网站的是落地服务器。中转段越"专"，晚高峰的确定性和抗封锁能力就越强——这就是为什么"专线机场"敢卖贵几倍：贵的不只是速度，是**高峰期不掉速的确定性**。

---

## 第三层：落地（目标地区出口）

落地服务器在目标地区（香港、日本、美国、新加坡……），它用当地的 IP 替你访问网站。这一层决定了三件重要的事：

1. **区域**：你看到的是"香港 IP"还是"美国 IP"，由落地决定；
2. **解锁**：Netflix 美区/日区能不能看、ChatGPT 能不能用，看落地 IP 是否被目标服务"认可"；
3. **风控**：跨境电商、账号注册这类场景怕"IP 脏"，落地 IP 是否原生、是否被标记为机房/代理，直接影响账号安全。

同一个机场里，"香港-01"和"香港-02"可能落地不同，解锁表现也不同。所以测流媒体解锁时，测的是**某个落地节点的 IP 质量**，而不是整个机场。

## 线路名词科普：CN2 / GIA / IEPL / IPLC / 原生 IP

买机场/看评测时高频出现的名词，一次说清（这部分内容也为后续独立专题埋个底）：

### IPLC（国际私有租用线路）

International Private Leased Circuit。**点对点私有专线**：从 A 地到 B 地拉一条独享线路，数据完全不走公网。因为不经过公网审查点，理论上"几乎不受封锁影响"，延迟极低（深港专线可低至 3–8ms）。代价是成本极高，真正用 IPLC 的机场不多，节点数也少。

### IEPL（国际以太网专线）

International Ethernet Private Line。由运营商（电信/联通等）提供的**以太网专线**，走运营商内网骨干，同样不经过公网。带宽规格高（接口常见 100Mbps–10Gbps），稳定性有运营商 SLA 保障，价格比 IPLC 亲民——所以现在中高端机场主打的"满血 IEPL"大多是它。

### CN2 / CN2 GT / CN2 GIA

CN2 是中国电信的第二代承载网（精品网络），分两档：

- **CN2 GT（Global Transit）**：半程精品，国际出口段走 CN2，价格适中；
- **CN2 GIA（Global Internet Access）**：全程精品，国内外都走 CN2，延迟低、绕路少、高峰期更稳，是电信线里公认最好的一档，价格也最高。

常说的"CN2 GIA 回国线路"，指美国服务器回中国这一段走 CN2 GIA 精品线路，不易被堵。

### 原生 IP

指 **IP 的注册归属地与其物理位置一致**的 IP——比如一个美国 ISP（Comcast、AT&T）实际分配给美国服务器的 IP 就是"原生美国 IP"。反例是"广播 IP"（注册地在欧洲、实际用于亚洲服务器）。原生 IP 是解锁流媒体、通过平台风控的重要基础；机场套餐里标"原生 IP"通常指落地用的就是目标地区 ISP 的地址段。

### 小结表

| 名词 | 一句话 | 常见出现在 |
|:----|:----|:----|
| 直连 | 节点就是境外服务器，流量直接出国 | 低价套餐 |
| 中转（BGP） | 国内/香港转发服务器 + 优质公网段 | 中端套餐 |
| IEPL | 运营商内网以太网专线，不走公网 | 中高端套餐 |
| IPLC | 点对点私有专线，成本最高 | 高端套餐 |
| CN2 GT / GIA | 电信精品网络两档，GIA 更好 | 回程线路描述 |
| 原生 IP | IP 归属地与物理位置一致 | 解锁/风控相关描述 |

> 📚 以上为行业通识整理，主要参考公开科普文章（[勇哥博客：IPLC 和 IEPL 专线有什么区别](https://yongjichang.com/wiki-iplc-vs-iepl) 等），具体线路的实测表现以你自己的测速/试用为准。

## 为什么套餐有"直连/中转/专线"之分

本质是**成本与确定性的权衡**：

- 直连便宜，但晚高峰国际链路拥堵时速度和稳定性"看天吃饭"；
- 中转贵一点，多一跳换来了绕开拥堵段的能力；
- 专线最贵，买的是**高峰期不掉速、抗封锁更强的确定性**——对币圈交易、跨境办公这类"掉线就是损失"的场景，这个确定性值钱。

所以别只盯着"专线=快"：干净线路上直连也能跑满；晚高峰专线的优势才真正体现。选套餐时先想清楚你的场景对"确定性"有多敏感。

## 我们实操过的类比：Cloudflare 橙云中转

机场的中转逻辑，和我们给自己服务套 Cloudflare 的思路高度相似。我们给 xhs.tochick.xyz 做过一套配置：

- **橙云（Proxied）**：把域名 DNS 设为 Cloudflare 代理模式，所有访客流量先到 Cloudflare 边缘节点，再由它回源到真实服务器——**用户的请求不直接打源站**，源站 IP 得以隐藏，还顺带获得 CDN 加速与抗攻击能力；
- **Origin Rules**：在边缘按请求规则改写回源地址/主机名，实现"同一个 CF 账户下，不同域名回不同源站"的精细控制；
- **灵活 SSL（Flexible SSL）**：访客到 Cloudflare 是 HTTPS，Cloudflare 到源站走 HTTP——源站不用自己配证书，证书与加密交给边缘层。

这和机场的"入口/中转"同构：CF 边缘节点 ≈ 机场入口，CF 骨干网络 ≈ 中转段，真实源站 ≈ 落地。理解了"流量先经过一层能加速、能隐藏源站的中转"这个模型，机场为什么爱套 CF、为什么中转能提升稳定性，就都顺理成章了。

> 💡 这层类比有个重要区别：Cloudflare 面向的是网站流量（七层 HTTP），机场中转面向的是代理流量（四层/加密隧道），但"中间加一层"的思路完全一致。

## 怎么选：按你的场景对号入座

- **轻度使用（刷网页、看视频）**：直连或中转套餐足够，不用为"用不上的确定性"多花钱；
- **晚高峰重度使用（4K 观影、下载）**：选中转以上，避免晚高峰掉速；
- **交易/办公/直播（掉线=损失）**：预算允许就上专线（IEPL/IPLC），买的是稳定性；
- **解锁与风控敏感（ChatGPT、Netflix、跨境电商）**：重点看**落地节点是否为原生 IP、解锁表现**，线路反而不是第一优先级——不知道怎么测解锁，看我们的 [流媒体解锁检测方法](streaming-unlock-test.md)；
- **不想研究这些**：直接看我们的 [场景导购](../README.md#-场景导购)，按你的需求对号入座；想对比套餐参数看 [机场对比表](../airports/README.md)。

## 常见问题

### ❓ 直连一定比专线差吗？

不一定。直连节点如果线路好（比如 CN2 GIA 回程）、用户少，体验可以很好；专线的优势主要在高峰期和抗封锁的"确定性"。以实测为准。

### ❓ 为什么有的机场"节点很多但都不稳定"？

节点数量≠质量。很多节点可能共用一个落地或中转带宽，超售严重时再多的节点也卡。判断一家机场，看它的专线/中转比例、晚高峰表现和口碑，比看节点数靠谱。

### ❓ "IPLC"和"IEPL"哪个好？

很难一概而论。IPLC 点对点、延迟极低但成本高；IEPL 走运营商内网骨干、带宽规格高、价格更亲民。对大多数用户，IEPL 的性价比通常更现实；同时要警惕把"公网中转"宣传成"专线"的机场——看实测和口碑，别只看文案。

### ❓ 解锁是线路决定的还是落地决定的？

落地（出口 IP）。同一个机场，香港节点能看港区 Netflix、新加坡节点能看新加坡区，就是因为落地不同。所以测解锁一定要**按节点测**，别拿一个节点的结果代表全机场。

### ❓ 机场会跑路吗？怎么降低风险？

任何机场都有经营风险。降低风险的办法：选有口碑、经营时间长的；月付为主、别一次性囤太长；重要的账号/交易场景用专线节点或自建节点兜底。自建方案见 [VPS 自建代理节点](vps-xray-setup.md)。

### ❓ 为什么我在国内访问机场官网经常打不开？

机场官网域名常被用于推广/防封跳板，域名变动频繁、国内访问时好时坏是常态。这也是为什么我们仓库里统一用短链入口跳转，而不是直接暴露域名——短链本身就是应对域名频繁变动的方案。
